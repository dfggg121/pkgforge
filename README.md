# PkgForge · 封装与符号一键生成

面向 **Allegro PCB Editor 16.6** 与 **OrCAD Capture / Design Entry CIS** 的本地工具：把器件引脚资料一次性生成可导入的封装引脚表、Capture 粘贴表、焊盘参数清单、校验图与原理图符号布局，可选同时产出 3D 模型。

Windows 免安装版，解压双击即用，不需要 Python；纯本地运行，只监听 `127.0.0.1`，不联网。

## 下载

到 [Releases](../../releases) 取最新版：`PkgForge-v1.4.5-x64-portable.zip`（约 11 MB），附 `SHA256SUMS.txt` 供校验。

## 它能做什么

- **封装参数与引脚**：器件名、封装类型（quad/dual/grid/single/custom）、mm/mil、焊盘尺寸、跨距、行列数；引脚编号支持数字、A1/B2 球号、EP/SH1 等标识
- **排列与尺寸**：圆周 / 椭圆排列、中心焊盘独立识别与吸附、引脚增加时本体与跨距联动；手动改宽长即固定尺寸
- **焊盘**：自绘（矩形/圆/圆角/多边形）、裁剪、栅格吸附；多形状本地库；钢网分格与开窗比例
- **符号**：两列基准 / 自动 / 功能分组三种排布，`section` 分块支持 FPGA 多单元符号，密集编号可显隐
- **模板**：QFN / QFP / SOIC / BGA / DIP / SIP / 径向 / 排针 / 多边形 / TO92 / TO220 等
- **校验**：错误阻止导出、警告需阅读后可"确认并清除"、可恢复、器件数据改动后相关警告自动重新出现
- **器件库**：导入后按内容版本保存，可搜索、重开，相同内容不重复存储，不覆盖原始文件
- **目录联动**：填写对接目录后自动递归扫描 `.pkgdoc.json` / 对接 JSON / Markdown 中的对接数据，坏文件单独报错不影响其它
- **给其他 Agent 的资料包**：一键打包指令、模板、格式说明与当前目录，便于让 Agent 填器件资料再导回
- **导出归档**：可按型号/版本/目标格式自动保存完整 ZIP 与器件快照
- **7 种目标**：Allegro、KiCad、AD、嘉立创 EDA 标准版/专业版、通用数据、全部格式
- **可选 3D**：总高度/离板高度/端子厚度确认后生成 STEP、OBJ+MTL、STL 与参数说明，可随全部 ZIP 或单独导出

## 导出的文件

| 文件 | 用途 |
|---|---|
| `*_pins.csv` | Allegro 引脚导入（ASCII、CRLF、5 行头） |
| `*_capture.tsv` | Capture 无表头 7 列粘贴表 |
| `*_pads.csv` / `*_pad_designer.txt` | Pad Designer 各层尺寸与分格参数 |
| `*_check.svg` / `*_cad.svg` | 编号几何校验图 / 深色 CAD 预览 |
| `*_symbol.svg` / `*_symbol_layout.csv` | 符号布局建议与坐标表（mil，Y 向下） |
| `*_report.md` / `*_README.txt` | 校验依据与导入步骤 |
| `*.pkg.json` / `*_manifest.json` | 完整描述与各文件 SHA-256 |

## 快速上手

1. 解压整个文件夹（保留 `_internal`），双击 `PkgForge.exe`
2. 启动窗口会显示本地地址并自动打开编辑器；首次使用先确认页面版本为 1.4.5
3. 「设置」里填对接文档目录 / 器件库目录 / 生成 ZIP 目录（填绝对路径，保存时自动创建）
4. 载入模板或导入对接文档 → 编辑 → 右侧看预览 → 导出 ZIP

关闭浏览器标签页不会停止服务；要退出请用启动窗口的「退出程序并停止服务」。默认端口 8765 被占用时会提示，关掉旧版本再启动。

## 系统要求

- Windows 10 / 11，64 位（本包为 x64 免安装版）
- 无需 Python、无需 Node.js、无需联网
- 需要 Allegro / Capture 时另装 Cadence 环境（软件本身不调用 Cadence）

## 边界（重要）

- **未在 Cadence 原生环境验收**：CSV/TSV 是按官方格式生成的可导入文本，实际导入与封装生成需在 Allegro/Capture 内完成并核对
- 符号 SVG 是**布局建议**，不是 Capture 的实际渲染结果；布局表也不是原生导入格式
- 3D 是**简化本体 + 可选焊盘投影端子**，不是厂商精确机械模型；无官方模型时给出明确标注的简化包络
- 模板与内置示例是演示数据，**使用前必须对照器件手册核对**
- 不内置大模型，也不自动识别 PDF；资料整理交给可下载的 Agent 资料包 + 人工核对
- 任何推算都带依据标记，无法确认的项目会明确标为待确认，不会替你编造数值

## 数据与隐私

- 所有文件只在本机读写，服务只监听 `127.0.0.1`
- 数据目录默认在程序旁的 `data/`（`settings.json`、`devices/`、`handoff/`、`exports/`）
- 升级时保留 `data/` 即可延续设置与器件库；换机器把整个文件夹拷走
- 程序不收集、不上传任何数据
