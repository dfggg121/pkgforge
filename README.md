# PkgForge · 封装与符号一键生成（多 EDA）

把一份器件引脚资料，一次生成**各家 EDA 都能用**的封装与符号资料：引脚表、符号粘贴表、焊盘参数、校验图、符号布局图，以及 KiCad / 嘉立创的原生库文件；可选同时产出 3D 模型。

Windows 免安装版，解压双击即用，不需要 Python；纯本地运行，只监听 `127.0.0.1`，不联网。

## 支持的目标 EDA

| 目标软件 | 产出 | 导入方式 |
|---|---|---|
| **Allegro / OrCAD Capture** | `*_pins.csv`、`*_capture.tsv`、`*_pads.csv`、`*_pad_designer.txt` | Pad Designer 建 padstack → Allegro `csvpin in` 导入引脚 → Capture 表格新建符号 |
| **KiCad 6+** | `.kicad_mod`（`.pretty` 封装库）+ `.kicad_sym` 符号库 | 加入封装库 / 符号库即可（原生格式） |
| **Altium Designer** | KiCad 格式库（`.kicad_sym` / `.kicad_mod` / legacy `.lib`） | `File > Import Wizard > KiCad Design Files` 转换后另存 SchLib/PcbLib |
| **嘉立创 EDA 标准版** | `*_symbol.json` + `*_footprint.json`（原生 JSON） | `文件 > 打开 > 嘉立创 EDA`，检查后另存个人库 |
| **嘉立创 EDA 专业版** | legacy `.lib` + `.pretty`（KiCad 5.1 格式） | 开始页 `导入 KiCad`，导入后建器件并核对符号/封装绑定 |
| **通用数据** | 完整 JSON、焊盘 CSV、符号布局 CSV、SVG | 自行转换到任意工具 |

选「全部已支持目标」会一次产出以上所有格式。每次导出还会附带该目标的 `*_README.txt` 导入步骤与 `*_compatibility.json` 兼容性清单。

## 它能做什么

- **封装参数与引脚**：封装类型（quad/dual/grid/single/custom）、mm/mil、焊盘尺寸、跨距、行列数；引脚编号支持数字、A1/B2 球号、EP/SH1 等标识
- **排列与尺寸**：圆周 / 椭圆排列、中心焊盘独立识别与吸附、引脚增加时本体与跨距联动；手动改宽长即固定尺寸
- **焊盘**：自绘（矩形/圆/圆角/多边形）、裁剪、栅格吸附；多形状本地库；钢网分格与开窗比例
- **符号**：两列基准 / 自动 / 功能分组三种排布，`section` 分块支持 FPGA 多单元符号，密集编号可显隐
- **模板**：QFN / QFP / SOIC / BGA / DIP / SIP / 径向 / 排针 / 多边形 / TO92 / TO220 等
- **校验**：错误阻止导出；警告可阅读后「确认并清除」，可恢复；器件数据一改，相关警告自动重新出现
- **器件库**：按内容版本保存，可搜索、重开，相同内容不重复存储，不覆盖原始文件
- **目录联动**：填对接目录后自动递归扫描 `.pkgdoc.json` / 对接 JSON / Markdown 中的对接数据，坏文件单独报错不影响其它
- **给其他 Agent 的资料包**：一键打包指令、模板、格式说明与当前目录
- **导出归档**：按型号 / 内容版本 / 目标格式自动保存完整 ZIP 与器件快照
- **可选 3D**：确认总高度/离板高度/端子厚度后生成 STEP、OBJ+MTL、STL 与参数说明

## 通用产物

| 文件 | 用途 |
|---|---|
| `*_check.svg` / `*_cad.svg` | 编号几何校验图 / 深色 CAD 预览 |
| `*_symbol.svg` / `*_symbol_layout.csv` | 符号布局建议与坐标表（mil，Y 向下） |
| `*_report.md` / `*_README.txt` | 校验依据、目标软件导入步骤 |
| `*.pkg.json` / `*_manifest.json` / `*_compatibility.json` | 完整描述、各文件 SHA-256、兼容性清单 |

## 快速上手

1. 解压整个文件夹（保留 `_internal`），双击 `PkgForge.exe`
2. 启动窗口显示本地地址并自动打开编辑器，确认页面版本为 1.4.5
3. 「设置」填对接文档目录 / 器件库目录 / 生成 ZIP 目录（绝对路径，保存时自动创建）
4. 载入模板或导入对接文档 → 编辑 → 右侧预览 → 选目标 EDA → 导出 ZIP

关掉浏览器标签不会停止服务；退出请用启动窗口的「退出程序并停止服务」。默认端口 8765 被占用时会提示。

## 系统要求

- Windows 10 / 11，64 位（本包 x64 免安装）
- 无需 Python / Node.js / 联网
- 目标 EDA 需自行安装对应版本（软件本身不调用任何 EDA）

## 边界（重要）

- 各目标格式按官方规范生成，**未在对应 EDA 内做原生导入验收**（`*_compatibility.json` 里统一记 `NOT_RUN`），导入后请自行核对
- KiCad 与嘉立创标准版输出原生库文件；AD 与嘉立创专业版走官方 KiCad 导入路线，本包不是预生成的 SchLib/PcbLib 或 `.elibz`
- 符号 SVG 是**布局建议**，不是任何 EDA 的实际渲染；布局表也不是原生导入格式
- 3D 是简化本体 + 可选焊盘投影端子，不是厂商精确机械模型
- 模板与内置示例是演示数据，**使用前必须对照器件手册核对**
- 不内置大模型，也不自动识别 PDF；资料整理交给可下载的 Agent 资料包 + 人工核对
- 任何推算都带依据标记，无法确认的项目明确标为待确认，不替你编造数值

## 数据与隐私

- 只在本机读写，服务只监听 `127.0.0.1`
- 数据目录默认在程序旁的 `data/`（`settings.json`、`devices/`、`handoff/`、`exports/`）
- 升级保留 `data/` 即可延续设置与器件库；换机器把整个文件夹拷走
- 不收集、不上传任何数据
